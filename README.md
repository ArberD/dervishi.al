# dervishi.al

Personal website and portfolio for Arber Dervishi.

## Project Structure

This repository contains the source code for my personal website, showcasing my work, projects, and professional information.

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000) in your browser
